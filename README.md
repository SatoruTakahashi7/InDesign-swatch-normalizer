# スウォッチ名とカラー値を整理

Adobe InDesign用のExtendScript（JSX）。ドキュメント内のCMYK／RGBプロセスカラーを選び、RGBをCMYKに変換してから、カラー値による命名と四捨五入を行います。バージョンはv1.0.0です。

## ダウンロード・使い方

1. [スウォッチ名とカラー値を整理.jsx](./スウォッチ名とカラー値を整理.jsx)を開き、Download raw fileで保存します。
2. InDesignの「ウィンドウ → ユーティリティ → スクリプト」を開き、「ユーザー」を右クリックしてFinderで表示します。
3. Scripts PanelフォルダにJSXを置きます。
4. ドキュメントを開き、スクリプトパネルからダブルクリックして実行します。
5. 一覧から対象を選び、命名・丸めの設定を選んで実行します。

## 設定

- **RGB→CMYK変換**：選択したRGBスウォッチをInDesignのカラー変換でCMYKに置き換えます。名前・丸めの設定にかかわらず実行します。変換値はInDesignのカラーマネジメント設定に依存します。
- **カラー値を名前にする**：`C=10 M=20 Y=30 K=40`などの名前を設定します。初期値はオン。
- **カラー値の丸め**：変更しない／1刻み／5刻み／10刻み。初期値は「変更しない」。
- 対象は複数選択可能。初期状態では全対象を選択しています。

5刻みの例：`C=13 M=26 Y=42 K=7` → `C=15 M=25 Y=40 K=5`。
RGBは先にCMYKへ変換し、変換後の値を丸めます。各チャンネルは0〜100に収めます。

## 注意事項と対象範囲

**RGB→CMYK変換と丸めは実際のカラー値を変更します。使用中の文字や図形の色にも影響します。最初は複製したドキュメントで試してください。**

- 特色、Lab、混合インキ、グラデーション、濃淡、標準スウォッチは対象外。
- 選択したRGBプロセスカラーをCMYKへ変換します。特色は対象外です。配置画像内のRGBは変換しません。
- 同名のスウォッチが存在する場合は、対象スウォッチの名前と値を変更せず、結果に表示します。統合は行いません。
- 名前は各チャンネルを整数に四捨五入した表示です。「変更しない」を選んだ場合、内部の小数値は保持します。
- 「カラー値を名前にする」はチェック専用APIではなく、値に一致する名前を設定する方式です。[Adobeコミュニティの実例](https://community.adobe.com/questions-671/change-all-swatch-names-to-name-with-color-value-843611)を参考にしています。
- 変更を1回の取り消しにまとめる設計です。
